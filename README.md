# Дневник тренировок

PWA для учёта силовых тренировок. Локальное хранение в IndexedDB (Dexie).

## Запуск

```bash
npm install
npm run dev
```

## Скрипты

- `npm run dev` — разработка
- `npm run build` — production-сборка
- `npm run lint` — ESLint
- `npm run format` — Prettier
- `npm test` — unit-тесты
